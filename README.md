
# Student Dropout & School Retention Analysis in Sri Lanka

## Project Overview
An interactive Power BI dashboard analysing student
dropout patterns, school retention, and education
resource distribution in Sri Lankan schools.

The project supports data-driven decision-making
by identifying districts and grade levels that may
require additional educational interventions.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modelling
- Microsoft Excel
- Data Visualization

## Key Findings
- Mullaitivu recorded the highest district dropout
  rate at approximately 3.16%.
- Grades 5, 9, and 10 showed higher dropout rates.
- Eastern and Northern provinces showed relatively
  high dropout rates.

## Data Sources
Sri Lankan school census education statistics
covering dropout, survival, enrolment, teachers,
and student-teacher ratios.

## Limitations
Dropout and gross survival rates measure different
outcomes and should not be directly interchanged.
Resource statistics have differing school coverage.
Observed relationships do not establish causation.
